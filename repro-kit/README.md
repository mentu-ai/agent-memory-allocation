# C29 reproducibility kit — curation vs. search sufficiency

This kit accompanies *Agent Memory Allocation: Tiers and Policies of Effective
Agent Memory* (`../paper-v1.md`). It lets a reviewer re-run the paper's central
experiment (§6.5) — grep-then-read (B) vs. curated layered disclosure (C), with
a flat-load baseline (A) and an oracle (D) — on a **public corpus**.

## What is and is not here (R2 release)

- **Included:** the harness (`repro_kit.py`, identical in logic to the committed
  experimental harness `analyses/c29-curation-vs-search-sufficiency/`), the
  public corpus list (`public-corpus.txt`, 17 operator-owned English documents),
  the generated public question set, and a demonstrator effect table.
- **Withheld, by design:** the paper's headline result used a **client corpus
  (85 Spanish operational notes) that is confidential and is not released.** Its
  question set, digest index, and per-run records stay private (see
  `../SENSITIVITY-AUDIT.md`). This kit reproduces the *method* on public data,
  not the exact headline numbers.

## The order proof does not require the withheld data

The paper's claim that the question set was frozen **before** any policy ran is
verifiable from the public git history — the content hashes were committed in
this sequence, timestamps and all:

```
5572eba  harness + design (no questions yet)
5d63e0a  questions-2026-07-19.json  sha256[:16] 8f39408f324ffb84   (FROZEN)
             index-2026-07-19.json  sha256[:16] c84e20581f36936f
…        first policy run (runs/ created)
dc5bfca  verdict: SUPPORTED
```

A reviewer confirms the ordering from commit metadata alone. The frozen
question file's hash is the commitment; its *contents* (client-derived) are
withheld.

## Run it

Requires the `claude` CLI on PATH and network access. Models are pinned in
`repro_kit.py` (answerer `claude-haiku-4-5`, generator `claude-sonnet-5`;
`--no-session-persistence` throughout).

```
python3 repro_kit.py questions     # generate + hash the public question set
python3 repro_kit.py run           # A/B/C/D over the 17 docs (resumable)
python3 repro_kit.py adjudicate    # deterministic effect table
```

Runs are stochastic; adjudication is deterministic over the recorded
`runs/*.json`. Expect the *direction* of the paper's result (B ≥ C on accuracy;
C incurs wrong-stops) to reproduce; exact magnitudes will differ — this is a
17-document English demonstrator, not the 102-question study.

## Provenance

`questions-public.json` / `index-public.json` are generated by `questions`;
`effect-table-public.json` by `adjudicate`. All three carry a note that they are
the public demonstrator, not the paper's result. The 17 source documents are the
operator's own methodology notes, audited free of client content on 2026-07-20.
