# Audit — mentu.ai `/research` section vs the corpus

*Date: 2026-06-13. Author: Claude (Opus 4.8). NOT corpus material — no verdicts.
Five public research "field declarations" on mentu.ai audited against the corpus
constitution, the C1–C5 verdicts, and `lineage/exclusions.md`. Read-only audit;
fixes are recommendations for the site (`children/apps/mentu-web-soon/app/research`).*

## The one cross-cutting fact

All five docs are dated **April 2026** (v1.0–1.1). They **predate the corpus
(founded 2026-06-10) and have never been reconciled with its verdicts.** So they
assert as settled the questions the corpus has since measured. Good news: **none
contain the worst excluded claims** (no consciousness %, no quantum/relativistic
"laws," no epistemic temperature). They are materially better than the 2025 theory
— most self-label design-principle / observed / hypothesis. The issues are
concentrated and fixable.

## The recurring overclaim (3 of 5 docs)

The **return/recursion loop is asserted as a working, delivered reality**:
- `recursive-self-improvement`: *"The local loop works."* / *"a closed feedback system… knowledge deepens with each cycle."*
- `architecture-of-living-intelligence`: *"local learning (which works today)."*
- `cognitive-infrastructure`: *"improves through its own operation."*

This is exactly what **C1 measured and refuted in its strong form, as instrumented**
(0/54 injected runs measurably consumed knowledge; the return loop is *open*). The
fix is the **corrected nuance**, not the opposite overclaim: reframe to *"the loop's
mechanisms are built and running; whether returning stored knowledge measurably
improves outcomes is under active test (C1b), after a first measurement found the
return arc open."* Do NOT write "recursion is refuted/broken" — C1 is *refuted
as-implemented, not retired as an idea*; recursion stays a live open thesis.
Clean lever (from the recursive-self-improvement audit): **split the recalibration
edge (execution→trust, real, C3a-consistent) from the return edge (substrate→next
run, open).** The docs currently fuse them into one "closed loop."

## Priority fix list (if the docs get updated)

1. **CRITICAL — reframe the return/recursion claims** in `recursive-self-improvement`, `architecture-of-living-intelligence`, `cognitive-infrastructure`: built-and-running mechanism + open-under-test (C1b), with the "refuted as-implemented, not as an idea" nuance. Split recalibration (real) from return (open).
2. **HIGH — the ADHD/autism "diagnostic landscape"** in `recursive-self-improvement`: cut or demote every clinical assertion to explicit speculation; delete "not metaphorical / genuine explanatory power." Same class the corpus retired as its largest credibility cost.
3. **HIGH — fix the factual error**: `cognitive-infrastructure`'s relationship enum → the real shipped set (`cites, extends, contradicts, refines, synthesizes, supports, questions, corrects`); schema "v7" → "v14".
4. **HIGH — stop citing platform self-counts as evidence** (245K/3.9M, 150+ sequences) across the docs — exclusion #6; use measured figures as scale context only, never as validation.
5. **MEDIUM — register discipline**: "law/algebra/near-semiring/dependent product" → "property/invariant/model"; preserve the design/observed/hypothesis tags (they are load-bearing).
6. **MEDIUM — reconcile `open-questions`** with the corpus's live state (cite C1b/C3a/C4; add the genuine open questions).
